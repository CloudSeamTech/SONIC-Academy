CLOUDSEAM TECH / SONIC-ACADEMY

Windows & Linux command cheat sheet

Definitions, examples and expected results. Reference only: no command runs here. Examples are not captured terminal output.

Type only after the prompt. PS means PowerShell; C:\…> means CMD; $ is a regular Linux-user prompt; # usually marks a root-user prompt. / is the Linux root directory; ~ is the signed-in user’s home.

Use your actual username and folder. dc01.lab.example.test is an example FQDN (full DNS name); DC01 is a short computer name. Example network targets must belong to your lab. Scratch-file exercises need your own dummy files.

Interactive reference

Windows

Get-Help PowerShell · Help · Read-only

Explains a PowerShell command and its parameters.

Start in: C:\Users\YourName

PS C:\Users\YourName> Get-Help Get-Service -Examples

Read it: Get-Service names the command; -Examples asks for examples.

Expect: Help examples appear; installed help may be limited.

Use it: Use when you know a command’s name but not its options.

Get-Content PowerShell · Files · Read-only

Reads a text file.

Read it: $env:WINDIR is the Windows directory; quotes keep the path together.

Sends ICMP requests to test whether a host replies.

Read it: -d skips reverse-name lookups; the IP is the example DC01 address.

Expect: Responding hops or timeout markers.

Use it: Check a route to your own approved lab target; some devices do not answer probes.

dcdiag CMD · Server & AD · Diagnostics; elevated DC session

Runs domain-controller diagnostic tests.

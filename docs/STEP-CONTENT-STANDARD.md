# Precise beginner steps

The main flow is **where to work → action → expected result → verification**. Keep the explanation to one or two sentences. Preserve exact commands, paths, required values, conditions and safety instructions; brevity must not remove information needed to complete the action.

Extra context, terminology and recovery help belong in one closed **Need help?** disclosure. Avoid several large explanation cards before the action. Source attribution stays visible beneath an image; longer provenance notes remain available when the image is enlarged.
